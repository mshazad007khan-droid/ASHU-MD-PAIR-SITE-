Questions

How do I get an ASHU-MD pair code?

Enter your number with country code, press Generate, then enter the code in WhatsApp → Linked devices → Link with phone number.

Is ASHU-MD free?

Yes, generating a pair code and linking the bot is free.

The code does not work. What now?

Use “Force new code” to reset your number's session, then try the fresh code. Codes expire quickly, so enter them right away.
